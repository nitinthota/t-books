# LoopBooks desk

One designer. Every module looks like this.

## Chrome

- Back
- Title in office words
- One short hint. No hive, tab, or submit jargon.
- Actions on the right: Save draft, then Post

## List

- Search field (shared Input)
- DeskChips under search
- Counts on the chips, not a second toolbar
- Table. Job names open the job.
- Row actions: Edit. Move only if the row has a job.

## Card

- Same frame
- Fields in two columns
- Money right-aligned
- Primary bank / first payment at the top of extra lists

## Words

| Stop | Use |
|---|---|
| Submit | Post |
| Save master | Save draft |
| people / payroll | Staff / Salary slips |
| hive row | — |
| this PC only | Draft stays here until you post |

## Do not

- A new chip style per module
- Raw HTML search on one desk and Input on another
- Engineer hints on the card
